KIR PWA — GitHub Pages

1. Buat repository GitHub, contoh: kir-pwa
2. Upload seluruh isi folder ini ke repository (bukan folder KIR_PWA_PRO-nya).
3. Buka Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: / (root).
6. Simpan dan tunggu GitHub Pages aktif.
7. Buka URL GitHub Pages Anda.
8. Di Chrome Android/desktop pilih Install KIR / Add to Home screen.

Backend tetap Apps Script:
https://script.google.com/macros/s/AKfycbyUeQ2HqZ7qg4klCgnye4wEB2VRAxKXsSguKTDilzp9cAAG-ylowjBCo8k4zaPgo5hr/exec

Catatan:
- PWA ini adalah shell profesional untuk aplikasi Apps Script.
- Google Sheets dan Code.gs tidak perlu dipindahkan.
- Kamera di iframe diberi izin melalui atribut allow.
- Service worker hanya meng-cache shell GitHub Pages, bukan data Apps Script.
